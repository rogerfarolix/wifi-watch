Privacy policy

Last updated: 3 November 2026

Wifi-Watch is a free, open-source project. This page covers two things: the website you are reading, and the Windows application. In short: no account, no cookies, no analytics and no telemetry.

The website

  • Hosting. The site is a static page served by GitHub Pages. GitHub may log technical data such as your IP address when you load it, under its own privacy statement.
  • No cookies, no analytics, no ads. I do not run any tracker.
  • Language choice. Your choice of English or French is stored in your browser (localStorage, key ww-lang). It never leaves your device. Clear your browser data to remove it.
  • Release information. Your browser asks the public GitHub API for the latest version, file size and download count. That request goes straight from your browser to GitHub.
  • Links. Buttons lead to GitHub, which has its own policy.

The application

  • No telemetry, no account, no cloud backend. Everything is stored on your PC, in your Windows user profile (%APPDATA%).
  • Secrets are encrypted at rest with Windows DPAPI: the webhook URL and the AbuseIPDB key.
  • Network data stays local. The device list, MAC and IP addresses, alerts and history are never uploaded.

Monitoring other people

If you use Wifi-Watch on a network used by employees, family members or guests, you are responsible for informing them and for respecting the law that applies to you (for example the GDPR in the European Union or your national data protection law). The tool lists devices and network activity; it does not read the content of anyone's traffic.

Your rights and contact

I hold no personal data about you, so there is nothing to export or delete on my side. For any question about this policy, open an issue on GitHub. For a security problem, use private vulnerability reporting.

If this policy changes, the date above will change and the history will be visible in the repository.

Politique de confidentialité

Dernière mise à jour : 3 novembre 2026

Wifi-Watch est un projet gratuit et open source. Cette page couvre deux choses : le site web que vous lisez et l'application Windows. En bref : aucun compte, aucun cookie, aucun outil d'analyse et aucune télémétrie.

Le site web

  • Hébergement. Le site est une page statique servie par GitHub Pages. GitHub peut enregistrer des données techniques comme votre adresse IP quand vous la chargez, selon sa propre politique.
  • Pas de cookies, pas d'analyse d'audience, pas de publicité. Je n'utilise aucun traceur.
  • Choix de la langue. Votre choix entre français et anglais est conservé dans votre navigateur (localStorage, clé ww-lang). Il ne quitte jamais votre appareil. Effacez les données du navigateur pour le supprimer.
  • Informations de version. Votre navigateur interroge l'API publique de GitHub pour connaître la dernière version, la taille du fichier et le nombre de téléchargements. Cette requête va directement de votre navigateur à GitHub.
  • Liens. Les boutons mènent à GitHub, qui a sa propre politique.

L'application

  • Pas de télémétrie, pas de compte, pas de cloud. Tout est stocké sur votre PC, dans votre profil Windows (%APPDATA%).
  • Les secrets sont chiffrés au repos avec Windows DPAPI : l'URL de webhook et la clé AbuseIPDB.
  • Les données réseau restent locales. La liste des appareils, les adresses MAC et IP, les alertes et l'historique ne sont jamais envoyés.

Surveiller d'autres personnes

Si vous utilisez Wifi-Watch sur un réseau fréquenté par des salariés, des proches ou des invités, c'est à vous de les informer et de respecter la loi qui vous concerne (par exemple le RGPD dans l'Union européenne ou votre loi nationale sur les données personnelles). L'outil liste les appareils et l'activité du réseau ; il ne lit pas le contenu du trafic de quiconque.

Vos droits et contact

Je ne détiens aucune donnée personnelle vous concernant : il n'y a donc rien à exporter ni à supprimer de mon côté. Pour toute question sur cette politique, ouvrez un ticket sur GitHub. Pour un problème de sécurité, utilisez le signalement privé de vulnérabilité.
